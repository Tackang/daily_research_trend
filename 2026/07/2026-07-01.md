🔬 Remote Sensing & Earth Observation

1. NIVA: A Multimodal Foundation Model for Actionable Earth System Intelligence `arXiv:2606.28546`
   - Trains a multimodal FM on large-scale Earth system simulations to learn unified ocean-atmosphere representations; proof-of-concept shows the model accurately predicts major climate variability indices (e.g., ENSO), extending forecast skill beyond the ~2-week predictability barrier.
   - Demonstrates that cross-modal structure between Earth system components can be learned end-to-end without task-specific supervision.
   - Why it matters: First FM targeting coupled Earth system dynamics—points toward general-purpose geospatial FMs that go beyond single-sensor EO modeling.

2. Cross-Sensor SAR Data Generation Using Diffusion Models and Feature Migration `arXiv:2606.28922`
   - Fine-tunes a multimodal diffusion transformer via LoRA to synthesize SAR imagery mimicking new satellite sensors; attention distillation transfers speckle texture, structural patterns, and radiometric characteristics from existing sensor data to the generative model.
   - Addresses data scarcity for newly launched SAR systems where real training data is unavailable, enabling cross-sensor model deployment.
   - Why it matters: Directly targets the cross-sensor generalization bottleneck critical for EO models adapting to next-generation SAR constellations.

3. GeoISF: Instance Semantic Forest for Large-Scale Cross-View Geo-Localization via Ground LiDAR-to-Satellite Image `arXiv:2606.28371`
   - Constructs a WordNet-based instance semantic forest to bridge the modality gap between ground-level LiDAR point clouds and overhead satellite imagery; semantic tokens serve as a shared medium across the two domains.
   - Achieves 13.22× improvement over prior LiDAR-to-image methods on R@10 on the KITTI dataset.
   - Why it matters: GPS-free geo-localization via 3D-to-satellite matching is a key enabler for autonomous mapping over large satellite image archives.

🤖 AI & Foundation Models

4. HExA: Hierarchical Experimentalist Agents `arXiv:2606.29315`
   - Training-free framework where LLM agents iteratively design and refine experiments, accumulate a reusable skill library, and integrate experimental evidence to answer queries; evaluated on Interphyre, a new physics simulation benchmark.
   - Boosts Claude Sonnet from 2% to 77% success on physics tasks; learned skills transfer zero-shot to harder variants (44%).
   - Why it matters: Active experimentation loops unlock dramatic capability gains in scientific reasoning without any gradient update—directly applicable to autonomous EO analysis pipelines.

5. RSEA: Recursive Self-Evolving Agents via Held-Out Selection `arXiv:2606.28374`
   - Iteratively refines agent strategy, skills, and playbook in natural language; a held-out validation gate discards updates that regress performance, making self-evolution monotonically safe across four benchmarks (ALFWorld, GAIA, τ-bench, WebShop).
   - Achieves 69.3% on ALFWorld vs. 64.6% for ReAct without any weight updates.
   - Why it matters: Practical recipe for safe self-improving agents—immediately applicable to automating iterative remote sensing analysis workflows.

6. Self-Supervised Theorem Discovery in a Formal Axiomatic System `arXiv:2606.28747`
   - Agent iteratively searches for proofs and extracts useful lemmas starting from axioms alone, building a growing library of tens of thousands of theorems without human-provided math libraries; presented at AI for Math Workshop @ ICML 2026.
   - Discovered theorems improve LLM reasoning when supplied as context, demonstrating emergent mathematical utility.
   - Why it matters: Proof that AI can bootstrap scientific knowledge from first principles—a foundational result for autonomous scientific discovery systems.
