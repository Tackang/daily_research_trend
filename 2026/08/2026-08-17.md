🤖 AI & Foundation Models
1. MindMemOS: A Portable and Self-Evolving Memory Operating Layer for AI Agents `arXiv:2608.12427`
   - Proposes a portable memory OS layer that lets LLM agents persist, evolve, and transfer long-horizon memory across tasks and sessions.
   - Why it matters: memory portability is a key blocker for agents that need to run long scientific workflows across tools.

2. Scaling Automatic Research Agents via World Models `arXiv:2608.12564`
   - Trains automatic research agents with RL inside simulated "world model" environments, cutting compute cost while keeping performance on empirical research tasks.
   - Why it matters: cheaper training loops for research agents could accelerate automation of hypothesis-testing pipelines.

3. Diagnostic Foundation for Evaluating LLMs' Research Integrity as Co-Scientists `arXiv:2608.12345`
   - Introduces a diagnostic framework to test whether LLM "co-scientists" fabricate, misreport, or overclaim results during automated research.
   - Why it matters: as AI agents get used for actual science, trust/integrity benchmarks become a prerequisite, not a nice-to-have.

4. Spatial Memory Agent: Experience-Grounded Procedure Memory for Spatial Intelligence `arXiv:2608.12743`
   - Builds an agent memory module that grounds procedural knowledge in past spatial experience for better navigation/manipulation reasoning.
   - Why it matters: spatial procedure memory is directly transferable to geospatial/EO agent tasks (e.g., site inspection agents).

5. DiG-bench: Discovery in Games `arXiv:2608.12593`
   - A benchmark testing whether agents can autonomously discover rules and hidden structure in game environments, as a proxy for scientific discovery.
   - Why it matters: open-ended discovery benchmarks are the standard tool for measuring "automate scientific discovery" progress.

6. Agent Behavioral Contracts II: Certifying Compositional Reliability Without Assuming Independence `arXiv:2608.12895`
   - Extends behavioral-contract theory for multi-agent systems to certify reliability when component agents are not statistically independent.
   - Why it matters: realistic multi-agent pipelines have correlated failures; this closes a gap in reliability guarantees.
