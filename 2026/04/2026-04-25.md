🔬 Remote Sensing & Earth Observation
1. ⭐ Pretrain Where? Investigating How Pretraining Data Diversity Impacts Geospatial Foundation Model Performance `arXiv:2604.21104`
   - Tests geographic composition of pretraining data for geospatial FMs across continents; European data outperforms global and continent-specific splits.
   - Among all diversity factors (continental, biome, landcover, spectral), only spectral diversity strongly correlates with downstream performance.
   - Why it matters: Spectral diversity > geographic spread for Landsat FM pretraining — a direct design cue for multispectral foundation models.

2. HyperFM: An Efficient Hyperspectral Foundation Model with Spectral Grouping `arXiv:2604.21127`
   - Proposes intra/inter-group spectral attention with hybrid parameter decomposition for NASA PACE hyperspectral data.
   - Outperforms existing hyperspectral FMs on four atmospheric retrieval benchmarks; releases large-scale HyperFM250K dataset.
   - Why it matters: Spectral grouping is a scalable architecture for wide-band satellite sensor foundation models.

3. Unlocking Multi-Spectral Data for Multi-Modal Models with Guided Inputs and Chain-of-Thought Reasoning `arXiv:2604.21032`
   - Training-free method adapts RGB-only LMMs (e.g., Gemini 2.5) to process multi-spectral RS imagery at inference via guided input adaptation.
   - Strong zero-shot LULC performance on RS benchmarks; accepted to IGARSS 2026.
   - Why it matters: Off-the-shelf frontier LMMs can tackle multi-spectral RS tasks without any specialized retraining.

🤖 AI & Foundation Models
4. GeoMind: An Agentic Workflow for Lithology Classification with Reasoned Tool Invocation `arXiv:2604.21501`
   - Frames geoscience classification as sequential tool-augmented reasoning; a global planner adaptively coordinates perception, reasoning, and analysis modules.
   - Process supervision enforces geological constraint alignment, outperforming static ML baselines on four well-log benchmarks.
   - Why it matters: Agentic tool-use injects domain priors into geoscience AI, enabling interpretable and geologically consistent predictions.

5. Co-Evolving LLM Decision and Skill Bank Agents for Long-Horizon Tasks `arXiv:2604.20987`
   - COSPLAY co-evolves an LLM decision agent and a learnable skill bank populated from unlabeled agent rollouts.
   - Achieves 25%+ average reward improvement over four frontier LLM baselines using an 8B base model.
   - Why it matters: Self-improving skill discovery co-evolved with decision-making is a key step toward scalable autonomous agents.
