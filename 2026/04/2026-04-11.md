📡 [2026-04-11] Daily Research Briefing

🔬 Remote Sensing & Earth Observation

1. **RemoteAgent: Bridging Vague Human Intents and Earth Observation with RL-based Agentic MLLMs** `arXiv:2604.07765`
   - Proposes an RL-trained agentic MLLM that interprets vague natural-language queries for EO tasks, delegating dense spatial predictions to specialized tools via Model Context Protocol. Introduces VagueEO, a new dataset pairing EO tasks with ambiguous human instructions.
   - Why it matters: First RL-based agent bridging imprecise user intent to concrete satellite image analysis pipelines, lowering the barrier for non-expert EO access.

2. **A PMP-inspired Evaluation Framework for Assessing Deep-Learning Earth System Models** `arXiv:2604.06567`
   - Applies PCMDI Metrics Package diagnostics to benchmark DL-based Earth System Models (ACE2, NeuralGCM), measuring reproduction of climatology and key variability modes against observational references.
   - Why it matters: Standardized DL-ESM evaluation is a critical step toward community trust and operational climate prediction with neural surrogates.

🤖 AI & Foundation Models

3. **Multi-Agent Orchestration for High-Throughput Materials Screening on a Leadership-Class System** `arXiv:2604.07681`
   - A hierarchical LLM-based system uses a central planning agent to dispatch parallel executor agents for screening metal-organic frameworks on the Aurora supercomputer, coordinated via MCP and Parsl workflow engine.
   - Why it matters: Demonstrates LLM multi-agent orchestration scales to HPC supercomputers — a replicable template for large-scale autonomous scientific computation.

4. **Rhizome OS-1: Semi-Autonomous Operating System for Small Molecule Drug Discovery** `arXiv:2604.07512`
   - Multi-modal agent team drives two oncology campaigns using a 246M-param GNN trained on 800M molecules; 91.9% scaffold novelty vs. known actives, ROC AUC 0.88–0.93.
   - Why it matters: Proves multi-role AI agent pipelines can deliver real molecular discovery at scale — new paradigm for early-stage drug design.

5. **From Papers to Property Tables: A Priority-Based LLM Workflow for Materials Data Extraction** `arXiv:2604.07584`
   - Three-tier LLM workflow (text/table → physics calculation → figure digitization) achieves 94.69% weighted accuracy across ~12,000 data points in 30 papers.
   - Why it matters: Automates structured dataset creation from unstructured literature without specialized model training.

6. **SEARL: Joint Optimization of Policy and Tool Graph Memory for Self-Evolving Agents** `arXiv:2604.07791`
   - Structured experience memory integrates planning + execution histories so RL agents reuse tools across tasks and densify sparse reward signals; accepted to ACL 2026.
   - Why it matters: Efficient self-evolving agent for resource-constrained settings — generalizes tool use without expensive multi-agent ensembles.

💡 One-line comment: Agents that reason, delegate, and evolve dominate today — from EO intent parsing to HPC-scale materials screening to self-improving RL systems.
