2. Discriminative World Models for Web Agents `arXiv:2609.02885`
   - Proposes a discriminative world-model formulation to improve perception and state estimation for autonomous web-browsing agents.
   - Why it matters: better internal world models are a recurring bottleneck for reliable long-horizon agent behavior.

3. Codebook Agent: Amortized Topology Design for LLM Multi-Agent Systems `arXiv:2609.02264`
   - Learns a reusable "codebook" of communication topologies to amortize the cost of designing multi-agent LLM system structures.
   - Why it matters: automating multi-agent architecture search could make agentic pipelines cheaper to deploy at scale.

4. CHIME: Credit-Aware Hierarchical Memory Evolution for Long-Horizon Agentic Planning `arXiv:2609.02074`
   - Introduces hierarchical memory that evolves based on credit assignment across long agent trajectories.
   - Why it matters: long-horizon memory management is key for agents running multi-step scientific or operational workflows.

5. Graph Machine: Towards Better Pretraining via Edges `arXiv:2609.02881`
   - Rethinks graph pretraining objectives by emphasizing edge-level structure rather than node-centric masking.
   - Why it matters: edge-aware pretraining could improve foundation models for relational scientific data.

6. UE5M3 FP4 Block Scaling for Stable Language Model Pretraining `arXiv:2609.02846`
   - Proposes an FP4 block-scaling numerical format to stabilize large-scale language model pretraining at low precision.
   - Why it matters: cheaper, stable low-precision pretraining lowers the cost barrier for training domain-specific foundation models.
